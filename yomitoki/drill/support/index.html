サポート（まほうのよみときドリル）

まほうのよみときドリルは、保護者の方のための iPhone・iPad アプリです。小学 1・2 年生向けの読解ドリル（運営が用意したもの）がアプリに入っていて、紙に印刷したり PDF にしたりして使えます。登録はいりません。

印刷のしかた

  1. ドリルを選び、「印刷する」を押します。「モモとピョン」は、購入しなくても、1回目のはじめの部分を無料で印刷できます。ほかのドリルは、「すべてのドリル（買い切り）」を購入すると「印刷する」が出ます。
  2. 子ども用（本文・問題用紙・ことばちょう）か、大人用（始める前に・解答と解説）かを選びます。答えが紙の裏に載らないように、子ども用と大人用は別々に印刷します。
  3. 紙面のプレビューで、白黒かカラーかを選びます。
  4. 「印刷する」で AirPrint 対応のプリンターに印刷します。「PDFを共有」で PDF を保存したり、ほかのアプリから印刷したりもできます。

すべてのドリル（買い切り）

  • アプリ内課金「すべてのドリル（買い切り）」は 1,000 円です。1回の購入で、アプリに入っているドリルすべてを、ずっと何度でも印刷・PDF 保存できます。
  • アップデートでドリルが追加されたときも、追加の支払いなしで使えます。
  • くり返しの請求はありません。購入代金のほかに支払いはありません。
  • 支払いは Apple ID に請求されます。支払いは Apple が処理し、アプリはカード番号などの支払いの情報を受け取りません。

よくある質問

機種変更をしました。アプリを入れ直しました

もう一度購入する必要はありません。本棚の右上のボタンから購入画面を開き、「購入を復元」を押してください。購入に使った Apple ID でサインインしている必要があります。

iPhone と iPad の両方で使えますか

使えます。同じ Apple ID でサインインして、もう一方の端末で「購入を復元」を押してください。

家族も使えますか（ファミリー共有）

使えます。Apple のファミリー共有で購入を共有していれば、ご家族はそれぞれの端末の購入画面で「購入を復元」を押すと使えます。

「購入は見つかりませんでした」と出ます

購入したときと同じ Apple ID でサインインしているか、通信できる状態かを確かめて、もう一度「購入を復元」を押してください。それでも戻らないときは、下のお問い合わせからご連絡ください。

返金してほしい

App Store での購入の返金は、Apple に申し込みます（運営者は返金の手続きを行えません）。手順は Apple のページをご覧ください: Appleから購入したアプリやコンテンツの返金手続きをする（申し込み先: reportaproblem.apple.com）。Apple が返金した購入は使えなくなり、鍵のかかった状態に戻ります（「モモとピョン」は無料の範囲に戻ります）。すでに印刷した紙や保存した PDF は、そのまま使えます。

印刷した紙と PDF について

印刷した紙やPDFは、ご家庭や教室でお使いください。販売やインターネットでの公開はしないでください。
