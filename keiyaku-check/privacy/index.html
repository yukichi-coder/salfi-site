契約書チェック準備AI プライバシーポリシー

施行日: 2026-10-31

塩野優希（Yuki Shiono・個人。以下「運営者」）は、アプリ「契約書チェック準備AI」（以下「本アプリ」）での利用者の情報の扱いを、次のとおり定めます。

1. 基本の考え方

  • 本アプリは、契約書の読み取り（OCR）・伏せる所の処理（サニタイズ）・確認ポイントの表示を、利用者の端末の中で行います。ただし、次の任意の機能を使うときだけは、利用者の端末から Ollama（米国・欧州）に送られます（3 章）。
  • 「AI による読み取り」（AI の OCR）を使うとき：伏せる前の契約書の画像が送られます（初めは「使わない」です。3-1）。
  • 「AI による確認ポイント」（AI のチェック）を使うとき：伏せたあとの契約書の本文（サニタイズ済みテキスト）が送られます（利用者が自分の Ollama の API キーを入れたときだけです。3-2）。
  • 運営者は、利用者が読み込んだ契約書の文字・画像を受け取るサーバーを持っていません。契約書の中身が運営者（開発者）のサーバーを通ることはありません。
  • 運営者は契約書を受け取らず、AI の学習にも使いません。（くわしくは 4 章）
  • 本アプリの出力は法的助言ではありません。

2. 端末の中で扱う情報

次の表は、AI による読み取りと AI による確認ポイントを使わない場合です。使う場合に端末の外へ出るものは、3 章のとおりです。

情報扱い
読み込んだ契約書（PDF・画像・貼り付けた文字）端末の中で読み取ります。運営者には送りません。AI による読み取りを使うときは、伏せる前の画像を、端末から Ollama に直接送ります（3 章）
サニタイズの結果・確認ポイント・プロンプト端末の画面に表示し、利用者が選んだときだけコピー・.txt に保存します。AI による確認ポイントを使うときは、伏せたあとの本文（サニタイズ済みテキスト）を、端末から Ollama に直接送ります（3-2）
Ollama の API キー（AI の OCR・AI による確認ポイントを使うときだけ）画面のメモリにだけ置き、保存・記録しません。アプリを閉じると消えます

3. Ollama に送る機能を使う場合（任意）

本アプリには、Ollama（Ollama Inc.、米国）の AI を使う任意の機能が 2 つあります。どちらも、利用者ご自身の Ollama の API キーで、利用者の端末から Ollama に直接送ります。運営者（開発者）のサーバーは通りません。

3-1. AI の OCR（画像の読み取り）

本アプリは、画像の契約書を読むときに、端末の OCR に加えて AI の OCR（Ollama のモデル）を使えます。使うかどうかは利用者が選びます（初めは「使わない」です）。

AI の OCR を使うと、次のようになります。

  1. 伏せる前の画像が送られます。画像の文字は読み取る前には伏せられないため、社名・氏名・住所・金額などが写ったままの画像が送られます。
  2. 送り先は Ollama（Ollama Inc.、米国）です。Ollama は、モデルと計算機を主に米国に置き、混み具合によって欧州で処理することがあると公表しています（https://ollama.com/pricing の Privacy）。
  3. 利用者ご自身の Ollama の API キーを使います。利用者が自分で Ollama と契約し、そのキーを本アプリに入れたときだけ使います。Ollama の料金は利用者と Ollama の間で発生します。
  4. 端末から Ollama に直接送ります。運営者（開発者）のサーバーは通りません。運営者は送った画像・読み取った文字・API キーを受け取りません。
  5. 送る前に同意をいただきます。上の 1〜4 を画面に示し、同意のチェックが入っているときだけ送ります。同意がない・キーやモデル名がないときは送らず、端末の OCR だけで読みます。
  6. Ollama での扱いは、Ollama のプライバシーポリシーに従います（https://ollama.com/privacy）。学習についての Ollama の公表内容は 4 章に書きました。

AI の OCR を使わなければ、画像は端末の外に出ません。

3-2. AI による確認ポイント（チェック）

本アプリは、伏せる所を確かめたあとの契約書の本文を、Ollama の AI に点検してもらい、確認ポイントを表示できます。使うのは、利用者が自分の Ollama の API キーとモデル名を入れたときだけです。キーを入れないときは「準備のみ」（伏せる所の確認・サニタイズ済みテキスト・プロンプトまで）で、Ollama には何も送りません。

AI による確認ポイントを使うと、次のようになります。

  1. 伏せたあとの本文（サニタイズ済みテキスト）だけが送られます。送るのは、利用者が画面で確かめた置き換え後の本文と、決まった指示文です。伏せる前の原本や画像は送りません。ただし、自動の置き換えは完全ではないため、伏せきれなかった言葉が残っていれば、そのまま送られます。送る前に、画面で必ず確かめてください。
  2. 送り先は Ollama（Ollama Inc.、米国）の https://ollama.com です。Ollama は、モデルと計算機を主に米国に置き、混み具合によって欧州で処理することがあると公表しています（https://ollama.com/pricing の Privacy）。
  3. 利用者ご自身の Ollama の API キーを使います。利用者が自分で Ollama と契約し、そのキーを本アプリに入れたときだけ使います。キーは画面のメモリにだけ置き、保存・記録しません。Ollama の料金は利用者と Ollama の間で発生します。
  4. 端末から Ollama に直接送ります。運営者（開発者）のサーバーは通りません。運営者は送った本文・点検の結果・API キーを受け取りません。
  5. 送る前に確認をいただきます。18 歳以上であることの確認と、上の 1〜4 を示した確認のチェックが入っているときだけ送ります。
  6. Ollama での扱いは、Ollama のプライバシーポリシーに従います（https://ollama.com/privacy）。学習についての Ollama の公表内容は 4 章に書きました。

AI による確認ポイントを使わなければ、本文は端末の外に出ません。

4. AI の学習について

学習に使われるかどうかは、契約書の中身がどこに渡るかで変わります。次の 3 つに分けてお知らせします。

  1. 運営者 — 運営者は契約書を受け取らず、AI の学習にも使いません（運営者は契約書を受け取るサーバーを持っていません。1 章）。
  2. AI の OCR・AI による確認ポイントで送る先の Ollama — 次は Ollama が公表している内容です（2026 年 10 月 30 日に確認。Ollama のプライバシーポリシー https://ollama.com/privacy）。Ollama は、クラウドのモデルを使うとき、入力と出力（プロンプトと応答）を要求を処理するあいだだけ扱い、それを超えて保存せず、AI のモデルの学習に使わないと書いています。運営者が Ollama と別に約束を交わしたものではなく、運営者が確かめたり保証したりできるものでもありません。この内容は Ollama が変えることがあります。
  3. 利用者が指示文（プロンプト）を自分の AI に貼る場合 — 貼った内容が学習に使われるかどうかは、その AI の設定や契約しだいです。運営者は関わりません。貼る前に、その AI が学習に使わない設定になっているかを確かめてください。本アプリでも、指示文を出す画面に同じ注意を表示しています。

5. 運営者が受け取る情報

  • 契約書の中身・画像・API キーは受け取りません。
  • お問い合わせ：利用者が support@salfi.org にメールを送ったときは、送信元のメールアドレス、メールに設定された名前、本文、添付ファイルを受け取ります。お返事と、不具合の調べと修正のためだけに使い、ほかの目的には使いません。メールは、運営者が使うメールサービスの中に保存します。対応が終わって必要がなくなったものは削除します。削除してほしいときは、同じアドレスにご連絡ください。契約書の本文・画像や、社名・氏名などは、メールに付けないでください。
  • アプリ内課金の購入と復元は、App Store（Apple）または Google Play（Google）の仕組みを通して行われ、各ストアのプライバシーポリシーが適用されます。運営者は、氏名やカード番号などの支払いの情報を受け取りません。アプリが受け取るのは、買い切りの購入が済んでいるかどうかの情報だけで、端末の中で使います。
  • アクセス解析・広告のための計測は入れていません。

6. 第三者への提供

運営者は、利用者の情報を第三者に売ったり渡したりしません。上の 3 章の Ollama への送信は、利用者が選んで同意したときに、利用者の端末から利用者のキーで行うものです。
