契約書チェック準備AI サポート

契約書チェック準備AIは、契約書を結ぶ前に、確認しておいたほうがよさそうな箇所に気づくための、一次チェックの支援アプリです（iPhone・Android）。本アプリの出力は法的助言ではありません。

お問い合わせ

感想・不具合の報告・お問い合わせは、メールでお送りください。

support@salfi.org

  • お返事は運営者が内容を確認してからお送りします。数日かかることがあります。

よくある質問

契約書が問題ないかを判断してくれますか？

いいえ。本アプリは、一般に確認されやすい箇所に気づくための参考情報を出すだけで、法的な判断や法的助言はしません。結果には誤りや見落としが含まれることがあります。契約を結ぶかどうかや、契約書を直すかどうかは、ご自身で判断し、必要に応じて弁護士などの専門家にご相談ください。

契約書の中身は運営者に送られますか？

いいえ。読み取り（OCR）・伏せる処理・確認ポイントの表示は、端末の中で行います。運営者は、契約書の文字や画像を受け取るサーバーを持っていません。

ただし、次の任意の機能を使うときだけは、端末から Ollama（米国・欧州）へ直接送られます（運営者には届きません。どちらも送る前に確認が出ます）。

  • 「AI による読み取り」：伏せる前の契約書の画像が送られます。この機能を使わなければ、画像は端末の外に出ません。
  • 「AI による確認ポイント」：ご自身の Ollama の API キーを入れたときだけ、伏せたあとの本文（サニタイズ済みテキスト）が送られます。キーを入れなければ「準備のみ」で、本文は端末の外に出ません。

くわしくはプライバシーポリシーをご覧ください。

読み込んだ契約書は保存されますか？

契約書と結果は、アプリを閉じると消えます。端末には保存しません。コピーや .txt の保存は、ご自身で操作したときだけ行います。

Ollama のアカウントは必要ですか？

「準備のみ」の機能（取り込み・端末での読み取り・伏せる処理・指示文のコピー）には要りません。キーが無いときは「準備のみ」で動き、ご自身の AI に貼る指示文までを作れます。

次の任意の機能を使うときだけ、ご自身の Ollama のアカウントと API キーが必要です。どちらも 18 歳以上の方だけがご利用いただけます。

  • 「AI による読み取り」：伏せる前の画像が、端末から Ollama（米国・欧州）へ直接送られます。送る前に同意の確認が出ます。
  • 「AI による確認ポイント」：伏せたあとの本文（サニタイズ済みテキスト）が、端末から Ollama（https://ollama.com）へ直接送られ、一般に確認されやすい箇所（確認ポイント）が表示されます。送る前に確認が出ます。キーは画面のメモリにだけ置き、保存しません。

Ollama の利用条件と料金は、Ollama の定めに従います。

伏せる処理（サニタイズ）は完璧ですか？

いいえ。社名・氏名・住所・電話番号などの候補を決まった規則で見つけますが、見落としがあります。ご自身の AI に貼る前に、必ず内容をご確認ください。原本データ（伏せる前の文章）を使う場合は、自己責任でお願いします。

どんな契約書に使えますか？

事業のための契約書（業務委託、秘密保持、売買など）の下準備を想定しています。すでに争いになっている、または争いになることがほぼ確実な案件（和解、内容証明への対応など）には使えません。弁護士にご相談ください。

料金はいくらですか？

App Store／Google Play のアプリ内課金で、買い切り 1,500円（税込）です。1 回の購入で、月額・年額などの定期的な請求や自動更新はありません。有料の機能の内容は、購入の前にアプリ内の購入画面でご確認ください。くわしくは特定商取引法に基づく表記をご覧ください。

機種変更や再インストールのあと、購入はどうなりますか？

購入したときと同じ Apple アカウント／Google アカウントで、アプリの「購入を復元」を押すと戻せます。もう一度お支払いいただく必要はありません。

返金はできますか？

App Store での購入の返金は Apple に申し込みます: Appleから購入したアプリやコンテンツの返金手続きをする。Google Play での購入は Google Play の返金に関するページをご覧ください。
